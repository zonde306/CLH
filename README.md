# CatalogHelper

## 安装与启动

1. 安装 **Node.js 22 或以上版本**，将安装目录加入环境变量 **PATH**。重新打开终端，确认能运行 `node -v` 和 `npm -v`。
2. 下载并解压项目，在包含 `package.json` 的目录打开终端，运行：

   ```sh
   npm ci
   npm start
   ```

3. 浏览器会自动打开。也可手动访问 `http://127.0.0.1:8787`。

Windows 用户可以双击 **`start.cmd`**，首次启动时会自动安装运行依赖。

端口被占用时，可运行 `npm start -- --port 8788`，然后访问 `http://127.0.0.1:8788`。关闭服务时，在终端按 **Ctrl+C**。

## 页面操作

1. 在首页选择已安装的模块。
2. 按页面提供的入口更新列表：点击 **“拉取新角色”**，或通过 **“导入角色清单”** 选择包含响应内容的 HAR 文件。
3. 使用搜索、筛选和排序查找条目；点击收藏按钮，将常用条目加入收藏。
4. 打开条目，按需要下载图片、动画、音频或剧情，也可选择下载全部资源。首次使用时，头像和其他媒体可能需要下载后才会显示。
5. 下载完成后，在对应分类浏览或播放。缺少播放器界面时，按页面提示下载或检查界面资源。
6. 下载中断或失败后，重新执行原下载操作即可复用已完成的文件。

## 安装可选依赖

如果下载时提示需要 Python，请先安装 **Python 3.13**，再运行：

```sh
npm run setup:python
```

按终端提示选择对应模块。Windows 用户也可以双击 **`install-python.cmd`**。

## 使用代理

需要通过代理访问上游时，在启动服务**之前**设置环境变量。支持标准变量名（小写优先）：

| 变量 | 说明 |
| --- | --- |
| `HTTPS_PROXY` | 访问 https 上游时使用，最常用 |
| `HTTP_PROXY` | 访问 http 上游时使用（未设时回退到 `ALL_PROXY`） |
| `ALL_PROXY` | 上面两项未设置时的回退值 |
| `NO_PROXY` | 直连名单，逗号或空格分隔；支持 `localhost`、`.example.com`、`10.0.0.0/8`、`127.0.0.1:8787` |

代理地址可省略协议（默认 `http://`），也可带账号密码；支持 `http://`、`https://` 与 `socks5://`：

```sh
# Windows（当前终端会话）
set HTTPS_PROXY=http://127.0.0.1:9080
set NO_PROXY=localhost,127.0.0.1
npm start

# macOS / Linux
export HTTPS_PROXY=socks5://user:pass@127.0.0.1:1080
export NO_PROXY=localhost,127.0.0.1
npm start
```

行为说明：

- 代理**完全由环境变量控制**：不设置则不使用代理，行为与之前一致。
- 走代理时由代理解析上游域名（本地不做 DNS 查询，兼容 Fake-IP 线路）；命中 `NO_PROXY` 的地址仍为直连并保持原有的公网地址校验。
- 上游连接统一通过 `CONNECT` 隧道（SOCKS5 为其标准命令），因此代理上不会出现明文请求；HTTPS 证书仍按原有策略校验。
- 地址/协议无法解析时只告警并回退为直连，不会中断下载；启动日志会打印实际生效的代理（隐藏凭据）。
- 浏览器不会自动继承这些变量，页面内流量指向本地服务，无需额外配置。

## 本地数据

已保存的完整模块目录可以放回 `games/<模块标识>/`，保留其中的 `game.json`、`src`、`viewer` 和 `dist` 等原有文件。回到浏览器页面或刷新后，模块会自动出现在列表中，可继续浏览已有内容和在线下载。请只安装可信来源的模块。

更新工具时，请保留自行安装的模块目录以及对应的 `parsed-data/<模块标识>/`；移除模块目录不会删除已下载内容。

下载内容保存在 `parsed-data/<模块标识>/`。

- **备份或迁移：** 关闭服务后，复制整个 `parsed-data` 文件夹。
- **清理原件缓存：** 关闭服务后，删除对应模块下的 `cache` 文件夹；`library` 中的已整理文件会保留，之后重新处理资源时可能需要再次下载原件。
- **保留已下载内容：** 保留对应模块下的 `metadata`、`state` 和 `library` 文件夹。

## 常见问题

- **无法启动：** 检查 Node.js 和 npm 是否可用，并重新运行 `npm ci`。
- **无法下载：** 检查网络后重试。使用代理时请设置 `HTTPS_PROXY` 等环境变量（见上方“使用代理”），并确认 `NO_PROXY` 未把目标域名纳入直连。
- **下载完成后页面未更新：** 点击页面的刷新按钮，并查看任务提示。
- **动画或音视频无法播放：** 使用支持 WebGL 的现代浏览器并开启硬件加速。
